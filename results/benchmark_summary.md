# CICIoT2023 Benchmark Summary

## Reported benchmark from the paper

- Accuracy: > 99%
- F1-score: approximately 0.99 for leading models such as Random Forest
- The paper demonstrates strong performance on multiple categories of IoT network attacks.

## Implementation summary

This repository contains a practical reproducible implementation using a Random Forest classifier with preprocessing and evaluation steps. The implementation is designed to work on the CICIoT2023 CSV files loaded from the local `data/` directory.

## Files

- `src/train_and_evaluate.py` — end-to-end implementation
- `results/benchmark_reference.json` — paper benchmark reference values
- `results/benchmark_metrics.json` — metrics generated by the implementation after training
- `results/benchmark_comparison.json` — comparison between the reported benchmark and implementation

## Expected outcome

The benchmark comparison is expected to show that the implemented Random Forest pipeline is competitive with the reported model performance, with results close to the published range (>99% accuracy, ~0.99 F1-score).
